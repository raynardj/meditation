# Bosch Process
A alternating gas approach to "drill" 5 µm wide but 50 µm deep hole on HBM chips, so they can communicate within the stack. It's doing CF6 gas to erode, C4F8 gas to protect, then blast a down direction hole on a protection.

Repeat the erode -> protect -> blast for hundreds of times.

# Prefix Code
When encode something with binary, from more frequent item to less frequent item, we can start with 0, 10, 110, 111... The decode can still work, without telling the deviding line between items, by creating new item code that the prefix doesn't collide with any existing item.
